# 🎓 Умный дежурный — Цифровой помощник студента (Бот + Сайт)

> «Умный дежурный» — это комплексное решение, состоящее из Telegram-бота и премиального Web-приложения. Оно закрывает самый частый сценарий использования: студенту не нужно рыться в расписании, чатах, картах и таблицах. Он просто задаёт вопрос обычным языком и получает ответ за секунды.

---

## 📋 Архитектура проекта

Проект состоит из двух слоев, работающих с общей базой данных SQLite:
1. **Telegram-бот (aiogram 3)**: Рабочее ядро в мессенджере.
2. **Веб-сайт (React + TS + Vite + Tailwind CSS)**: 
   - **Landing Page (`/`)**: Презентационная страница с интерактивным чат-симулятором.
   - **Web App (`/app`)**: Мобильный интерфейс (в phone mockup на desktop) с вкладками Помощник, Пары, Где я?, Лекции и Профиль. Поддерживает переключение тем (день/ночь) и выбор группы.
   - **Панель администратора (`/admin`)**: Панель для CRUD-управления данными (логин: `admin`, пароль: `admin123`).
3. **API-бэкенд (FastAPI)**: Связывает React-приложение с базой данных бота и повторно использует NLP-парсер.

## 🚀 Быстрый старт

### 1. Настройка окружения
Создайте файл `.env` в корневой директории на основе `.env.example`:
```ini
BOT_TOKEN=твой_токен_от_BotFather
DEFAULT_GROUP=ИС-21
```

### 2. Запуск Telegram-бота
```bash
# Установите зависимости
pip install -r requirements.txt

# Запустите бота
python run.py
```

### 3. Запуск API-бэкенда
Бэкенд запускается на порту `8000` и предоставляет REST API для сайта.
```bash
python run_api.py
```

### 4. Запуск Фронтенда (Сайта)
```bash
# Перейдите в папку web
cd web

# Установите npm-зависимости (если не установлены)
npm install

# Запустите dev-сервер
npm run dev
```
После запуска dev-сервер будет доступен по адресу: **`http://localhost:5173/`**

## 🔗 Маршруты сайта (Роутинг)

Сайт использует `HashRouter` для корректной работы без настройки wildcard-запросов на хостинге:
- **`http://localhost:5173/#/`** — Landing Page (презентация проекта)
- **`http://localhost:5173/#/app`** — Web App (веб-версия помощника)
- **`http://localhost:5173/#/admin`** — Панель администратора

---

## 🎨 Дизайн и темы интерфейса (Day/Night)

Дизайн сайта и Web App разработан в стиле финансового интерфейса с премиальной коричнево-графитовой гаммой и мягкими оранжевыми акцентами:
- **Night Mode (по умолчанию)**: глубокий графитово-коричневый фон (`#1B1512`), стеклянные карточки (glassmorphism), оранжевое свечение.
- **Day Mode**: тёплый молочно-бежевый фон (`#F7F1EA`), светлые стеклянные карточки, мягкое оранжевое свечение сверху.
- Переключение происходит без перезагрузки страницы с помощью кнопки `ThemeToggle`. Выбранная тема сохраняется в `localStorage` пользователя.

---

## 💬 Логика распознавания вопросов (NLP)

Интерфейс Web App отправляет запросы на `/api/query`, где бэкенд использует тот же NLP-парсер, что и бот:
- **Опечатки**: Поймет «корпуст», «распасание», «матав», «щас ведет».
- **Сокращения предметов**: `матан` → математический анализ, `прога` → программирование, `бд` → базы данных, `инглиш` → английский язык.
- **Геолокация**: Запрос «Где сейчас Петя Иванов?» проверит доступ пользователя. Если доступ закрыт (как у Анны Смирновой), вернет вежливый отказ.

## ⚙️ Управление данными (Админка)
Панель `/admin` защищена базовой авторизацией (логин: `admin`, пароль: `admin123`).
Вы можете добавлять, редактировать и удалять:
- Пары в расписании (изменения мгновенно применяются для бота и сайта).
- Корпуса вуза и их адреса.
- Преподавательский состав.
- Записи лекций и ссылки на видео.

## 🎯 Демо-сценарий для клиента (Защита MVP)

При показе проекта клиенту выполните следующие шаги:
1. **Покажите бота**: Напишите боту в Telegram: «Где 5 корпус?» или «Кто ведёт матан?». Бот отвечает.
2. **Откройте сайт**: Перейдите на `http://localhost:5173/#/` — покажите стильный Лендинг.
3. **Проверьте смену темы**: Нажмите на переключатель день/ночь в верхнем правом углу. Обратите внимание на плавный переход цветов.
4. **Запустите демо**: Нажмите «Открыть демо» — откроется Web App в рамке телефона.
5. **Сделайте запрос**: Введите в чат помощника: «Кто ведет матан?» или нажмите на быстрый чип. Получите мгновенный ответ.
6. **Покажите расписание**: Перейдите во вкладку «Пары». Покажите расписание группы ИС-21, текущую пару и ее статус (Идёт/Скоро/Завершено).
7. **Покажите карту**: Перейдите в «Где я?» и откройте детали 5 корпуса.
8. **Покажите лекции**: Перейдите в «Лекции», отфильтруйте пропущенные и откройте запись.
9. **Смените группу**: В «Профиле» смените группу на `ЭК-11` — расписание во вкладке «Пары» перестроится автоматически.
10. **Покажите админку**: Перейдите на `/admin`, авторизуйтесь, измените время пары расписания и покажите, что в Web App пара обновилась.

    │   ├── index.css               # Цветовые переменные тем день/ночь

    │   │   └── UI.tsx              # StatusBar, ThemeToggle, PhoneMockup, etc.
