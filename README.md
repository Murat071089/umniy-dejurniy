# 🎓 Умный дежурный — Telegram-бот для студентов

> Пока мы делаем нативное приложение, ядро логики уже работает. Этот бот закрывает самый частый сценарий использования: студенту не нужно рыться в расписании, чатах, картах и таблицах. Он просто задаёт вопрос и получает ответ. Мы экономим студентам до 20 минут в день.

---

## 📋 Функции MVP

| Функция | Описание |
|---------|----------|
| 📅 **Расписание** | Расписание на сегодня, завтра, следующая пара |
| 🏫 **Корпуса** | Поиск корпуса по номеру, адрес, описание, ссылка на карту |
| 🚪 **Аудитории** | Поиск аудитории: этаж, корпус, описание |
| 👨‍🏫 **Преподаватели** | Кто ведёт предмет, кафедра, ближайшая пара |
| 🎧 **Записи лекций** | Поиск записи по предмету, тема, дата, ссылка |
| 📍 **Геолокация** | Где сейчас студент (с проверкой разрешения) |
| 🎤 **Голосовые** | Заглушка с вежливым fallback |
| 🤖 **NLP** | Понимает сокращения (матан, физра, инфа) и опечатки |
| 👤 **Профиль** | Группа, геолокация, настройки |

## 🚀 Быстрый старт

### 1. Создай Telegram-бота

1. Открой Telegram и найди [@BotFather](https://t.me/BotFather).
2. Отправь команду `/newbot`.
3. Придумай имя и username для бота.
4. Скопируй полученный **токен**.

### 2. Настрой проект

```bash
# Клонируй / скачай проект
cd "проект Имрана"

# Создай файл .env
copy .env.example .env
```

Открой `.env` и вставь свой токен:

```
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
DEFAULT_GROUP=ИС-21
```

### 3. Установи зависимости

```bash
pip install -r requirements.txt
```

### 4. Запусти бота

```bash
python run.py
```

Бот запустится и начнёт принимать сообщения. В консоли появится:

```
✅ База данных инициализирована.
🌱 Тестовые данные загружены!
🚀 Запуск бота «Умный дежурный»...
✅ Бот запущен и ожидает сообщения.
```

## 💬 Примеры вопросов

Боту можно писать обычным языком:

| Вопрос | Что делает |
|--------|------------|
| `Где 5 корпус?` | Покажет адрес, описание и ссылку на карту |
| `Где аудитория 204?` | Покажет корпус, этаж и описание |
| `Расписание на завтра` | Расписание для группы пользователя |
| `Какие пары сегодня?` | Расписание на сегодня |
| `Следующая пара?` | Ближайшая пара |
| `Кто ведёт матан?` | Преподаватель + ближайшая пара |
| `Есть запись лекции по истории?` | Ссылка на запись |
| `Где сейчас Петя Иванов?` | Геолокация (если разрешена) |
| `Где деканат?` | Местоположение деканата |
| `Где столовая?` | Местоположение столовой |

**Бот понимает сокращения:**
- матан = математический анализ
- физра = физическая культура
- инфа = информатика
- прога = программирование
- бд = базы данных
- инглиш = английский язык
- бжд = безопасность жизнедеятельности

**Бот понимает опечатки:**
- «где 5 корпуст» → корпус 5
- «кто ведет матав» → матан
- «распасание на завтра» → расписание на завтра

### Сценарий 1: Поиск корпуса
```
Пользователь: Где 5 корпус?
Бот: 5 корпус — Лабораторный корпус. Адрес: ул. Университетская, 7. [ссылка на карту]
```

### Сценарий 2: Преподаватель
```
Пользователь: Кто ведёт матан?
Бот: Математический анализ у группы ИС-21 ведёт Иванова Наталья Александровна. Ближайшая пара: сегодня в 09:00, 3 корпус, аудитория 204.
```

### Сценарий 3: Расписание
```
Пользователь: Расписание на завтра
Бот: [список пар с временем, аудиториями и преподавателями]
```

### Сценарий 4: Геолокация (разрешена)
```
Пользователь: Где сейчас Петя Иванов?
Бот: Петя Иванов сейчас в: 3 корпус, аудитория 205. Обновлено 7 мин. назад.
```

### Сценарий 5: Геолокация (запрещена)
```
Пользователь: Где Анна Смирнова?
Бот: Анна Смирнова не открыл(а) доступ к своей геолокации. Я не могу показывать местоположение без разрешения.
```

### Сценарий 6: Запись лекции
```
Пользователь: Есть запись лекции по истории?
Бот: Да, есть запись: «Российская империя в XIX веке». [ссылка]
```

### Сценарий 7: Голосовое сообщение
```
Пользователь: [голосовое сообщение]
Бот: Я пока не смог разобрать голосовое сообщение. Напиши вопрос текстом, и я быстро отвечу!
```

### Сценарий 8: Опечатка
```
Пользователь: где 5 корпуст
Бот: [корректный ответ о 5 корпусе]
```

### Сценарий 9: Профиль
```
Пользователь: /profile
Бот: Имя: ..., Группа: ИС-21, Геолокация: выключена [кнопки управления]
```

## 🔧 Как менять тестовые данные

Тестовые данные загружаются при первом запуске из файла `src/database/seed.py`.

Чтобы обновить данные:

1. **Удали файл** `smart_duty.db` (база данных пересоздастся при следующем запуске).
2. **Отредактируй** `src/database/seed.py` — там все данные в понятном формате.
3. **Запусти** бота снова: `python run.py`.

### Что можно изменить:

- **Группы** — массив `groups`
- **Корпуса** — массив `buildings`
- **Аудитории** — массив `rooms`
- **Предметы** — массив `subjects` (вместе с алиасами в JSON)
- **Преподаватели** — массив `teachers`
- **Расписание** — массивы `schedule_today` и `schedule_tomorrow`
- **Записи лекций** — массив `lecture_records`
- **Студенты** — массив `users`

> 💡 Расписание автоматически привязывается к реальным датам (сегодня/завтра), поэтому на демо оно всегда актуально.
